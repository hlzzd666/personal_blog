# 开放式海上航海人物展台 Design QA

## 范围

- 目标页面：`/gallery` 桌面端 WebGL 场景与移动端二维降级。
- 当前基线：开放海面、石材直线步道、两侧人物展台、黄铜相框和罗盘嵌花。
- 本轮仅同步文档，没有运行浏览器视觉复测；以下项目均需在下一次视觉验收时确认。

## 验收清单

| 验收项 | 当前实现依据 | 复测状态 |
| --- | --- | --- |
| 连续开放海面 | 单一大尺寸海面平面紧贴步道边缘，使用平铺海水贴图 | 待复验 |
| 海面动态与减少动态偏好 | 海水贴图仅在未启用减少动态时滚动 UV | 待复验 |
| 晴日海天与自然阴影 | 全景环境、半球光、环境光与方向光提供日间照明 | 待复验 |
| 直线主步道与纵深 | 洞石步道贯穿展位区，按人物数量计算长度 | 待复验 |
| 双侧人物展台 | 最多 40 位人物按全局顺序在步道左右排列 | 待复验 |
| 相框材质层次 | 黄铜浮雕、深海蓝衬框、背板、铆钉和编号铭牌 | 待复验 |
| 入口视觉锚点 | 罗盘嵌花与导航圆环位于步道入口和纵向节点 | 待复验 |
| 无围护建筑结构 | 不渲染玻璃墙、顶棚、玻璃地面或室内水池 | 待复验 |
| 桌面端交互 | Pointer Lock、移动、准星注视、点击或 `E` 打开档案 | 待复验 |
| 移动端降级 | 小屏或不支持设备显示二维人物档案列表 | 待复验 |

## 复测方式

- 桌面端以 `1440x900` 打开 `/gallery`，检查入口、海面连续性、日间光照、相框层次及无顶棚/玻璃围护结构。
- 锁定视角后移动至人物展台，确认海报加载、高亮、点击与 `E` 打开档案，以及暂停和继续流程。
- 移动端以 `390x844` 检查二维列表、文字可读性、焦点状态与无溢出。
- 检查控制台、网络请求和画面，确保无资源 404、WebGL 错误或黑屏。
