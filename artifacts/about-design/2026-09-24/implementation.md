# 关于我：图 2 开发约定

- 选定视觉：`night/night.png`（本轮三张输出中的第二张），1536 × 1024。用户已明确选择并授权直接开发，不再次进行风格抽选。
- 范围：现有 `/about` 全页，导航内容、入口和交互保留，只适配夜色；其余模块依参考延展，所有数据继续来自既有公开接口。
- THESIS：夜航工作台承载个人介绍，读者从人物与主张进入项目、技术、经历，再抵达生活与联系。
- OWN-WORLD：深海 #061a22、工作面 #0d2933、帆布字 #f3edda、辅助 #a9bbc0、黄铜 #e2bc74；有质感的真实航海器物图像和安静的连续文字记录面。
- STORY：身份与主张 → 项目和技术 → 自我介绍 → 工作经历 → 兴趣和所在地 → 本站介绍 → 联系。
- FIRST VIEWPORT：左侧头像、问候、动态主张和联系/简历，右侧月夜航船、罗盘、日志；下方露出项目与技术并列模块。
- FORM：用户选择图 2 的参考实现。原导航既有字体/图标/内容按明确要求保留；项目数据无图片字段，不伪造项目封面；较长的真实文案允许自然换行。
- 动效：单幅独立航海素材的缓慢景深变化与鼠标视差，滚动时经历航线渐进绘制，章节刻度显现、按钮反馈、简历弹窗过渡。支持暂停、离屏/隐藏停止、减少动态偏好、触屏降级。
- 不固定姓名长度、项目/经历/技能/兴趣条数，不生成新的工作经历，不添加技能百分比或成就数。
- 地图与已有简历/联系功能保留，视觉不依赖本地数据库的具体公司、城市或条目数量。

## 已实施与验证范围

- 生产素材为 `web/public/about/night-voyage.webp`，1536 × 1024，约 202 KiB；请求及来源记录保留在 `production-hero/`。实现为独立图像结合 CSS 视差和缩放，不包含实时 WebGL 船体或流体水面。
- 首次请求失败不使用原硬编码示例资料；保留重试入口。合成数据覆盖 5 条项目、5 段经历、18 个技术、长姓名与长文案、空数组、无简历和无坐标等情况。
- 简历使用原生 dialog，支持 ESC、焦点恢复和关闭卸载；地图延迟加载并处理卸载/异步竞争。页面继续读取既有接口，未修改数据库和后台编辑字段。
- 最终桌面 1536 × 1024、手机 390 × 844 视觉及交互验收证据写入系统临时目录 `about-night-qa`，避免将真实资料截图纳入仓库。详细结果见项目根 `design-qa.md`。
