# 关于我：夜航工作台升级实施说明

用户选定 `night/night.png`（图 2）后，进一步要求首屏底座具有跨出画面的效果，并让整页摆脱连续堆叠内容的结构。本轮仍在现有 `/about` 内实现，全站导航保留原内容和交互，仅适配夜色；资料继续来自既有公开接口，不调整数据库或后台字段。

## 当前页面结构

1. **分层首屏。** 左侧为动态身份、主张与联系 / 简历操作；右侧海景与透明器物分开渲染。海面单独裁切，航船、罗盘、日志和完整圆台独立叠放，底座跨过首屏边界，在章节导航上方留出净空。手机按文字实际高度排布，并保留船体展示空间。
2. **项目档案。** 左侧索引选择一份项目，右侧纸面显示时间、职责、简介、技术栈与可选链接；前后按钮与方向键、Home / End 共用选择逻辑。手机索引横向滚动，当前项自动进入索引可视范围。技术工具箱对照当前项目技术名高亮，匹配忽略大小写、常见分隔符和版本数字。
3. **个人手记与工作航程。** 简介、签名与真实指标置于独立记录面；工作经历采用停驻标题、阅读航线、节点与连续条目，使内容层级不同于项目区。
4. **屏幕之外。** 海岸旅行主题插画承接兴趣标签，所在地以倾斜的小地图卡片显示。图面高 185px，隐藏地图内部与卡片重复的标题，保留地图品牌信息与加载降级。
5. **本站与联系。** 本站说明沿用动态介绍、技术栈和可选仓库入口；联系区保留动态邮箱、社交入口与留言入口，纸色明信片复用海岸图，按钮可切换至既有微信二维码并返回正面。

项目、技能、工作经历、指标、兴趣和社交链接没有固定数量。空数组显示整理状态或按模块条件隐藏；简历 URL 为空时不展示简历操作。首个接口请求失败保留错误与重试，不使用本地示例人物替代。姓名、公司、城市和数量均不写入页面布局约束。

## 视觉与素材

固定夜色由深海 `#061a22`、工作面 `#0d2933`、帆布字 `#f3edda`、辅助字 `#a9bbc0`、黄铜 `#e2bc74` 组成。项目档案与明信片使用 `#e8e0ca` 纸面，给长页提供亮度变化。复杂场景由栅格资产承担，SVG / 图标组件只用于简单功能符号；标题、正文和所有操作均为网页元素。

| 当前生产资产 | 用途 | 规格 |
| --- | --- | --- |
| `web/public/about/night-sea.webp` | 月夜海面背景 | 1536 × 1024，约 140 KiB |
| `web/public/about/night-workbench.webp` | 完整圆台、航船、罗盘与日志前景 | 1536 × 1024 RGBA，约 289 KiB |
| `web/public/about/quiet-harbor.webp` | 生活区海岸场景及联系明信片 | 1536 × 1024，约 191 KiB |

三图合计约 620 KiB。图像来源与提示词见同名 `.webp.json`，生成资料在 `upgrade-assets/` 与 `life-assets/`。工作台保留接口返回的透明蒙版，仅清理极低透明度噪声和近不透明边缘，没有用几何蒙版截取底座。海景与前景请求质量均为 high，接口报告分别为 low / medium；请求参数不能被当成实际输出质量。生活图是装饰性场景，不代表真实个人旅行照片。

旧版单张 `night-voyage.webp` 与 `production-hero/` 保留历史来源，当前首屏不再引用它们。此前单幅背景的整图裁切方案已被上述两层替代。

## 动效与交互实现

- 首屏海景与实体工作台按不同幅度滚动，工作台叠加鼠标轻视差与 11 秒缓慢浮动；独立前景层承载底座越界。
- 项目详情切换使用短促的透明度与空间过渡，档案纸面和明信片只在鼠标输入时轻微倾斜；技能高亮反馈当前项目。
- 个人手记轻转，工作航线随阅读绘制，节点与经历分段显现；海岸背景、所在地卡片与联系明信片随阅读产生不同幅度的空间移动。二维码由明确按钮切换，不自动翻面。
- `useAboutMotion` 以 IntersectionObserver 维护可见场景，滚动 / 尺寸事件只申请合并后的单帧更新，统一读布局后更新进度变量；条目显现只触发一次。刷新与卸载使用代次和销毁状态防止异步回调重新接管已离开的页面。
- 章节导航有暂停开关；首屏离开视口暂停浮动，页面隐藏停止场景更新；触屏不使用鼠标视差。减少动态偏好与无观察器路径保留完整静态内容。运行时沿用 Vue、CSS 与浏览器原生 API，无新增依赖。
- 项目索引具备 tablist / tabpanel 语义与可见焦点；简历沿用原生 dialog，支持关闭和 ESC，关闭即卸载 iframe。地图复用原延迟加载组件及配置缺失、坐标缺失、加载失败的中文备用状态。

这些空间效果属于栅格图像与 CSS 变换，不包含实时 WebGL 船体、真实水面流体或完整 3D 翻书引擎。
