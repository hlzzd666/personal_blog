# 夜航工作台分层素材

此次将旧版单张 `night-voyage.webp` 拆为海景与工作台两个独立图层，前景可真实跨过首屏的章节边线，而不是让图片矩形一起越界。

- `web/public/about/night-sea.webp`：1536 × 1024，143,402 字节，无透明通道。保留月夜海面、山体与月亮，移除船、工作台、书与罗盘。
- `web/public/about/night-workbench.webp`：1536 × 1024，295,714 字节，RGBA。保留完整椭圆金属厚底、梅利号、索具、罗盘、日志、地图与绳索。可见边界为 `(82, 41, 1466, 946)`，底部留有 78 像素透明区。

## 生成与处理

两张都使用旧版 `production-hero/night-voyage.png` 为参考，通过已配置的本机 image2-api 编辑接口生成。提示词、干运行检查及生成元数据保留于本目录；接口运行元数据已被项目统一规则忽略，不包含访问凭据。两次提示词检查均通过，无警告。

接口请求 `high`，响应海景标记 `low`、工作台标记 `medium`，因此不宣称接口实际返回 high。已目视确认最终画面清晰度与网页展示比例匹配。

本机 skill 文档认为模型不支持透明输出，因此前景提示词原计划采用纯洋红底去色；实际接口在 `background=auto` 的情况下直接返回了带精细 alpha 的 PNG（响应背景标记 `transparent`）。最终保留该真实 alpha 通道，没有采用几何形状裁切。原始透明区 RGB 存有光晕，忽略 alpha 的预览会误显示为黑底光晕，网页正常 alpha 合成不会出现。

`prepare_assets.py` 使用 Pillow 导出两张 WebP，仅清除 alpha≤3/255 的背景残留、将 alpha≥248/255 设为完全不透明。已在深青色与米白底上检查细索具、旗杆、帆边和完整椭圆底座，无白边、洋红溢色、明显剪切或硬折线。`foreground/edge-check.jpg` 为边缘检查，`foreground/teal-preview-final.jpg` 为最终合成检查。

## 放置建议

海面放在首屏独立裁切容器；工作台放在首屏外层的 `overflow: visible` 视觉层，层级高于下一章背景但低于页面操作。桌面图像宽度约 950–1050 像素，图像 bottom 为约 -130 像素时，考虑 78/1024 的底部透明留白，实体底座能跨章节线约 75–80 像素。下一章需留出对应上间距。移动端依据文字高度自然置于下方，并保留少量越界；不要将前景作为 `background-image` 与海面一起裁切。
