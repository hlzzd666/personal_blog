# 模块讨论清单

具体业务模块在实现前，先确认以下内容：

## 首页

- 首屏要表达的个人定位和核心行动
- 航海日志视觉元素的使用范围
- 是否需要精选文章、航海地图、时间线、订阅入口
- PC、平板、手机端的优先级

## 文章

- 文章列表筛选：标签、分类、搜索、分页
- 文章详情：目录、代码高亮、图片、阅读量、分享
- 文章状态：草稿、已发布、下线
- URL、SEO、Markdown 编辑方式

## 关于自己

- 展示内容：简介、技能、经历、联系方式、社交链接
- 是否需要可编辑时间线和头像/封面上传
- 哪些信息公开，哪些信息只在后台可见

## 管理后台

- 登录方式、管理员角色和权限
- 文章编辑器、草稿自动保存、预览和发布流程
- 媒体资源管理
- 操作日志和数据统计

## 数据与非功能

- MySQL 版本、部署方式和备份策略
- 是否需要 Redis、对象存储、邮件服务
- 是否需要国际化、暗色模式、评论和 RSS
