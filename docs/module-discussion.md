# 模块讨论清单

具体业务模块在实现前，先确认以下内容：

## 首页

- 首屏要表达的个人定位和核心行动
- 航海日志视觉元素的使用范围
- 是否需要精选文章、航海地图、时间线、订阅入口
- PC、平板、手机端的优先级

## 文章航行大屏

- 用户已确认 `artifacts/blog-dashboard/article-focus/文章大屏-设计稿.png`，独立前台路由 `/dashboard`，主导航提供入口；大屏不显示原首页导航和页脚，标题罗盘可返回首页。
- 固定 1672 × 941 设计画布，按窗口可用宽高的较小比例整体缩放、居中留白，包含全屏和小屏；不拉伸、不裁切、不再切换纵向布局。画布保留七类 ECharts 图表：月度发文、文章分类、专题文章量、技术标签、近 7 日访客统计、文章篇幅、文章发布日历。
- 仪表盘仅展示本站文章；通过现有匿名公开文章列表与专题接口汇总，支持按年份筛选。
- 后台“站点设置”维护 `dashboard_show_entry` 和 `dashboard_years`，沿用站点设置 JSON 持久化及管理员 Session/CSRF 写权限，无数据库结构变更。默认显示入口，默认年份为 2024、2025、2026；年份必填 1 至 12 项，范围 1970～2100，保存后去重升序，前台初次加载选最新年份。入口关闭仅隐藏导航按钮，不封禁公开路由。
- 年度图表按所选自然年统计；累计指标与分类、篇幅、标签、专题统计截至所选年截止日。阅读和点赞为文章当前累计值，不伪造历史计数快照。访客统计按服务器日期展示近 7 日每日访问次数，与后台“今日访问”口径一致，不参与大屏年份切换。
- 提供年度切换、刷新、全屏、图表悬停、文章明细筛选，以及加载、空数据和错误状态；接口失败不以示例数据冒充本站统计。
- 中央直接加载既有梅利号 GLB，以 OrbitControls 支持旋转、缩放、复位和自动旋转。拖动不改变自动旋转开关，松手后按原状态继续；页面隐藏时暂停渲染，减少动态偏好下停止自动旋转。不支持 WebGL 时显示已渲染素材并保留所有文章图表。模型区域不显示署名小字，来源与许可保留在素材清单中。
- 等比缩放后的留白使用同一海面素材的柔化延伸，维持画布比例及内容区布局。
- 文章数据仅在前端内存聚合；访客统计通过公开只读聚合接口返回每日访问次数，不公开 IP、位置、来源、User-Agent 或访问路径。Markdown 字数按解析后的正文计算，排除代码块、链接地址与图片地址。

## 文章

- 文章列表筛选：标签、分类、搜索、分页
- 文章详情：目录、代码高亮、图片、阅读量、分享
- 不设置草稿和已发布状态，文章写入后直接进入博客内容
- URL、SEO、Markdown 编辑方式
- 后台维护标题、摘要、封面、转载标记、作者、来源链接、发布时间、更新时间、浏览量、点赞数、标签和分类
- Markdown 内容使用可预览编辑器，发布时间和更新时间允许管理员选择日期时间格式
- 前台按归档、标签、分类组织文章；归档以发表时间整合为一条时间线，详情首次加载增加一次浏览量。公开点赞按文章和匿名访客标识做唯一记录，详情回显当前访客的点赞状态，重复请求不重复累加
- 文章列表页可维护背景图、装饰图和信息卡视觉层，默认按 `article_list_background` 读取，兼容旧的 `archive_background`
- 全站导航提供文章检索入口：关键词匹配标题、摘要与 Markdown 正文；结果展示文章分类、发表时间和摘要，点击后进入文章详情
- 搜索弹层限制键盘焦点在弹层内，关闭后把焦点还给触发入口；首页分类直达对应筛选结果；文章归档保留自动续载，并提供可键盘操作的“加载更多文章”按钮
- 管理接口使用服务端 Session 鉴权；公开文章读取和点赞保持匿名访问，文章管理列表和写接口需要管理员会话
- 文章可以选择一个专题并维护专题内顺序；删除专题只解除文章关联，不删除文章
- 文章详情提供专题优先的上一篇、下一篇和最多三篇相关推荐，并支持系统分享或复制链接回退
- 移动端文章详情提供阅读进度、可展开目录和回到顶部；每篇文章的阅读位置仅保存在访问者浏览器，文章更新时间变化时旧位置自动失效，再次进入时由访问者选择是否继续阅读，不自动跳转

## 文章分类与标签管理

- 后台使用一个“分类与标签”页面，分别维护文章分类和标签的名称、排序及引用数量。
- 文章分类为单选，标签为多选；文章编辑页和列表筛选只选择已维护的项目，不支持临时创建。
- 分类或标签被文章引用时禁止删除，避免历史文章内容被隐式修改。
- 新增管理表和文章关联表，保留文章旧的 `category`、`tags` 字段作为接口及历史数据兼容镜像。
- 首次迁移自动从已有文章去重创建分类、标签并完成关联；空分类归入“未分类”。

## 专题

- 前台使用 `/series` 和 `/series/:slug` 展示专题及其有序文章航线
- 专题维护名称、别名、简介、封面和后台排序；文章数量由关联关系实时统计
- 公开读取保持匿名访问，创建、更新、删除使用管理员 Session 鉴权
- 删除专题只将关联文章的专题和专题顺序置空，不删除文章

## 短动态

- 前台使用 `/notes` 和 `/notes/:slug`，支持 Markdown、标签、发布时间和可选外部链接
- 短动态具有稳定永久链接，按发布时间倒序展示，不接入导航栏文章搜索
- 公开读取保持匿名访问，创建、更新、删除使用管理员 Session 鉴权
- 删除短动态只删除自身记录，不影响文章、专题或媒体之外的业务数据

## 关于自己

- 导航与页面统一命名为“关于我”，使用独立前台路由 `/about`
- 公开展示个人介绍、状态、头像、工作经历、项目经历、技术栈、兴趣、联系方式、社交链接和关于本站
- 工作经历、项目经历、技术栈与社交链接均支持后台增删、排序和编辑；技术栈每项维护名称与上传图标，头像与技术图标沿用媒体上传能力
- 关于我资料采用单例数据模型，通过 `/api/v1/about-profile` 读写，公开接口只返回页面实际展示字段
- 关于我支持后台上传 PDF 简历，资料保存后前台提供下载与站内在线预览入口
- 城市与经纬度在关于我后台维护；前台地图使用高德地图 JS API，Key 与安全密钥由前台环境变量提供，不写入业务数据或仓库
- 关于我公开读取保持匿名访问，后台写入、媒体上传和媒体清理使用服务端 Session 鉴权

## 访客定位展示

- 首页信息舱展示访问者 IP、城市、地区和国家，不写入数据库或业务日志
- 后端调用第三方 IP 地理定位服务，需在站点隐私说明中告知访客
- 仅配置为可信的反向代理可传递 `X-Forwarded-For`，避免伪造来源地址
- 站长地址名称与详细经纬度仅由后台维护；后端计算访客与站长的直线距离，前台不返回坐标原值

## 访客记录

- 所有公开前台路由在导航完成后记录一次访问，不记录后台、API、静态资源和上传文件请求
- 记录保存原始 IP、城市、地区、国家、页面路径、Referer、User-Agent、设备类型和访问时间
- 前台不读取 GPS、不申请浏览器权限、不要求用户授权；IP 由后端从请求中获取，并可能发送给 IP 地理定位服务查询位置
- 记录永久保存，后台提供分页筛选、单条删除和按访问日期范围批量删除

## 管理后台

- 登录方式采用 Redis 服务端 Session、HttpOnly Cookie 和 CSRF 双提交；第一版仅支持单管理员账号，不做多角色
- 文章编辑器、预览和内容库维护；文章写入后直接进入归档、标签和分类体系
- 媒体资源管理
- 媒体资源管理提供上传目录文件列表、引用状态识别、文件预览、链接复制和未引用文件清理；清理范围仅限上传目录内且未被文章、站点设置、关于我资料引用的文件
- 操作日志和数据统计
- 控制台读取真实文章数量、浏览量、点赞量和热门文章；文章管理仍可手动调整浏览量和点赞量

## 每日问答自动发布

- 后台维护启用状态、北京时间、OpenAI 兼容接口地址、模型、加密 API Key、发布周期、主题、AI 角色、生成要求、问答数量、文章模板和失败重试规则
- 每日、每周或每月按配置生成问答 JSON，数量为 1-20，结构校验通过后直接公开，不增加草稿流程
- 文章作者、专题、分类和标签从后台配置读取；分类和标签复用文章分类与标签管理，不允许在每日问答页面临时创建
- 标题、别名和摘要模板支持 `{date}`、`{year}`、`{month}`、`{day}`，别名必须含 `{date}` 以保证同日幂等
- systemd timer 每分钟检查一次配置；自动任务按配置尝试并重试，同日重复执行不得重复创建文章或消耗 AI
- API Key 使用服务器主密钥加密保存，后台和 API 只显示是否已配置，不回显任何 Key 内容
- 最近运行结果、尝试次数和失败原因在后台展示，由管理员手动刷新，第一版不提供邮件或短信通知

## 站点公开页面与分发

- 全站提供页脚、版权信息、隐私说明和未知路由 404 页面
- 隐私说明披露访客 IP 记录、定位用途、数据保存和管理员删除方式
- 公开文章提供 RSS，文章、专题和短动态进入 sitemap；导航栏搜索仍只检索文章

### 2026-09 设计图还原

- 2026-09-23 补充：前舱改为六件主题道具常设展（草帽、电话虫、单针记录指针、和道一文字、橡胶果实、梅利号）。每件提供外观辨识点、关联故事和参考来源，沿用 E/点击查看；仅前台策展数据，无新增业务接口或权限。

- 用户要求完整实现已生成的船长舱设计图。入口使用由设计图提取的独立高清场景素材，文字、导航、检索、展签、章节与罗盘均为真实网页元素；进入漫游后加载同一材料语言的实时 Three.js 船长舱。
- 实时空间改为封闭胡桃木舱室、宽舷窗、黄铜灯具、船长桌椅、望远镜、船模玻璃柜与地面罗盘；展位随公开人数延伸，保留 0～40 人和最多 12 张邻近海报纹理。
- 初版四章曾依人物姓名关联公开档案；2026-09-24 起由下述后台分类配置替代，按数据库中的分类编号关联。
- 九位已识别角色有 AI 生成馆藏插画，管理员海报优先，缺失/失效时使用对应插画；其他人物保留中性编目海报。素材为非官方同人展示，来源与生成说明见 [展馆设计说明](gallery-design/museum.md)。
- 桌面提供章节阅读、检索、档案、实时漫游和返回序厅；小屏显示相同视觉序厅与可访问的二维馆藏。搜索和阅读均仅在公开数据上进行；初版未新增 API，后续分类管理的接口与迁移见下文。

- 前台使用 `/gallery` 提供 PC 端第一人称人物展厅；鼠标控制视角，方向键或 `WASD` 移动，`E` 或点击查看人物档案
- 当前展厅采用宽约 10 米的封闭船长舱，由 Three.js 程序化几何与本地材质构建，按后台全局顺序自动布展；人物不足时不创建空相框。旧开放甲板与 GLB 船舱不再作为当前画廊运行时方案
- 靠近展位高亮，注视展位后点击或按 E 查看档案；右上角船舱航图显示玩家位置、朝向和视野内展位，画面导航显示展位编号与距离
- 船舱每段长 3.4 米，至少 6 段，最多 20 段；根据公开人物数量扩展，0 位时也可进入空船舱。角色图片在运行时贴入，后台修改海报不需要重建模型
- 展厅设置维护名称、入口标题、Logo 开关和 Logo 图片；人物维护姓名、称号、势力、悬赏、能力、简介、台词、海报、展示状态和顺序
- 最多保存 40 位人物，包含隐藏人物；公开接口只返回启用人物，后台读取全部人物
- 人物海报为空或加载失败时，已识别角色使用本地馆藏插画，其余人物使用程序化占位海报；正式图片沿用媒体上传与引用清理能力
- 管理写接口使用管理员 Session 和 CSRF，公开读取保持匿名；新人物默认隐藏，演示人物默认展示
- 不做人物模型、音频、移动端漫游、WebGPU、瞬移、后台 3D 预览和服务端图片派生；保留现有 Session、CSRF、上传压缩与图片字段契约，分类管理按下述方案迁移数据库
- 小屏、触摸设备、WebGL2 或 Pointer Lock 不可用时提供二维人物档案列表；实时场景初始化失败、图形上下文丢失时也可继续查阅档案
- 人物档案筛选标签对应 `gallery_chapters` 数据，后台可维护名称、副标题、章节说明、故事文案、排序和公开状态；人物通过 `chapter_id` 归属分类。公开接口只返回启用的分类，人物未分类时仍出现在“全部馆藏”。

## 前台图标系统

- 前台提供 24 枚海贼王世界观器物图标，覆盖主导航、内容操作、媒体功能和状态反馈；图形先保证功能语义，再体现航海主题。
- 图标使用统一的深海蓝、黄铜金、珊瑚红和帆布白多色位图语言，不使用角色头像或官方 Logo，并标注为非官方同人风格视觉。
- 每枚图标以 256 × 256 透明 PNG 交付，页面按 20、24、32、48 或 64 像素等比例显示；16 像素场景继续使用简化通用符号。
- 图标跟随系统浅色或深色偏好调整外圈、底纹和投影；交互状态由 CSS 表达，减少动态偏好下关闭位移动效。
- 前台使用 `/icons` 公开展示图标名称、用途和建议尺寸，入口放在页脚而非主导航。
- 图标目录不读取业务数据，不新增后端接口或写入权限；生成提示词、模型与非敏感来源信息随资产保留。

## 留言板（首版）

- 独立前台路由 `/guestbook`，访客匿名提交昵称和纯文本留言；不收集邮箱，不支持访客账号、Markdown、嵌套回复和邮件通知。
- 所有留言默认 `pending`，管理员在后台“留言板”审核后才公开；支持通过、拒绝、标记垃圾和软删除，首版不做公开自动发布。
- 新增 `guestbook_messages` 表，保存昵称、内容、状态、匿名访客哈希、内容指纹、风险分数、审核时间和软删除时间；公开接口只返回已审核留言。
- 公开 API 使用 `/api/v1/guestbook`，列表采用页码分页；提交接口返回 202 和审核中状态。后台列表、状态更新和删除使用管理员 Session/CSRF。
