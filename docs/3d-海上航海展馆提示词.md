# 旗舰船舱人物展馆

## 场景与数据

`/gallery` 使用 Blender 导出的旗舰船舱模型：单层木船舱连接前后甲板，包含胡桃木拱肋、帆布顶、采光带、椭圆舷窗、黄铜装饰、护墙板、罗盘与舵台。整体宽度 10 米，内舱约 6 米净通道。船舱长度随公开人物数量增长，基础 6 段、最多 20 段，每段 3.4 米，艏甲板 9 米、艉甲板 7 米。

后台接口仍为 `/api/v1/gallery`。保留 `settings`、`characters`、`poster_url`、`is_visible`、`sort_order` 等现有字段，无数据库变更。前台按顺序布置 0～40 位人物；人物照片、姓名及档案由业务接口读取，没有烘焙进建筑模型。小屏和触摸设备使用二维档案。

## 模型资产契约

- `web/public/gallery/flagship/flagship.glb` 包含四个命名根节点：`CabinBay`、`BowDeck`、`SternDeck`、`ExhibitFrame`。不应改名，缺少节点会触发二维回退。
- Blender 使用 Z 向上；导出 GLB 使用 Y 向上。前台地面为 Y=0，视点高 1.7 米，朝船首为负 Z。
- 第一个舱段中心为 Z=0，其后按 -3.4 米排列；前后甲板连接到实际船舱两端。相框位置由 `web/src/gallery/layout.json` 与 `layout.ts` 计算。
- 四个结构单元内部按材质合并几何体，克隆时共享纹理和几何体。相框高亮只克隆其黄铜材质。
- GLB 内嵌木材、黄铜与帆布的颜色、粗糙度、法线贴图。Blender 源文件另含离线预览光照和海面；Three.js 使用自己的物理天空与实时海面，不依赖 Blender 专用节点。
- 颜色贴图使用 sRGB，法线和粗糙度为线性数据。木材颜色从批准的主视角图派生；法线、粗糙度是视觉估算，非实物扫描。

## 交互和资源管理

- 鼠标控制视角，WASD 或方向键移动。E 或点击打开当前注视且距离 4.5 米以内的展位，Escape 暂停。打开档案暂停移动，关闭后恢复漫游；二维档案关闭不会请求 Pointer Lock。
- 小地图每秒更新 10 次，标示船体、前后甲板分界、玩家位置及方向、18 米以内视野中的展位。画面上同时保留最多 4 个不互相遮挡的编号和距离标记。
- 墙面、相框、船边、舵台和桅杆具有保守碰撞边界。地面无台阶，不支持跳跃或飞行。
- 最多保留邻近 12 个展位需要的海报纹理，分辨率上限 512×768；按原比例完整显示，不裁切人物海报。远处或失败图片恢复到人物信息占位图，返回附近时重新加载。
- 失焦和切换标签页停止移动。减少动态偏好关闭海面滚动。退出路由释放事件、控件、几何体、材质、纹理、环境贴图和渲染器；异步返回的过期资产也会释放。

## 生成与复现

设计图和材质提示词位于 `docs/gallery-design/`。非敏感生成记录位于 `artifacts/gallery/reference/`，包含主视角、俯视图、柚木与胡桃木四次调用的提示词、请求摘要、提示检查和输出元数据。运行时不请求图片生成接口。

```powershell
python scripts/gallery/generate_references.py
python scripts/gallery/generate_references.py --materials
python scripts/gallery/prepare_materials.py
& D:/Blender/blender.exe --background --factory-startup --python scripts/gallery/build_flagship.py
& D:/Blender/blender.exe --background --factory-startup --python scripts/gallery/validate_model.py
npm run build:web
npm run lint:web
.venv/Scripts/python.exe -m unittest tests.test_gallery
node scripts/gallery/check_browser.cjs
```

图片脚本交互读取密钥或使用已有进程变量 `IMAGE_API_KEY`，不保存密钥。依赖 image2-api 技能、Python requests/Pillow/numpy、本地 Blender；浏览器检查脚本需要 Node 可解析 `playwright` 及本地 Chrome，依赖放在外部运行环境时可设置 `NODE_PATH`。浏览器用真实公开接口内容派生测试样本，不写数据库。

## 验收边界

- `.blend`、渲染图及哈希报告位于 `artifacts/gallery/model/`；浏览器截图、容量、交互、兼容性与性能记录位于 `artifacts/gallery/qa/`。
- 主视角和俯视图是 AI 概念参考，不是几何测量图。俯视图重复了若干尺寸文字；接口请求 1024×1024，实际返回 1254×1254，以元数据为准。
- 两个木材提取任务接受了编辑范围检查提示，因为目标是从参考画面提取完整材质，而非局部修图。
- 建筑按参考重建并已多轮校正，但细部连接件、舵台、船尾轮廓、环境和真实材质微结构仍有简化，不能宣称严格 1:1。Blender 离线路径追踪与浏览器实时光照也不可能逐像素一致。
- 60fps 是桌面性能目标，实际硬件、分辨率、后台任务和浏览器会影响结果。以检查报告中的环境与采样值为准，不能泛化为全部中端设备保证。
