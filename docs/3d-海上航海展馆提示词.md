# 海上航海人物展台：现行场景说明

本文档记录前台 `/gallery` 的当前运行时设计与实现边界。以 `web/src/gallery/GalleryScene.ts` 为准；它不是旧版玻璃展馆的素材生成提示词。

## 场景构成

- 场景是开放式海上人物展台：一条浅色洞石直线步道架设在开阔海面之上，并形成纵深视线。
- 海面以 `calm-ocean-color-tile.png` 平铺，运行时缓慢滚动 UV；用户启用“减少动态效果”时停止滚动。
- 步道两侧按全局排序陈列人物展台和相框，最多 40 位人物；人数不足时不创建空展位。
- 入口步道嵌有罗盘玫瑰，并沿步道设置受控数量的导航圆环。
- 相框使用黄铜浮雕纹理、深海蓝衬框、档案背板、铆钉、编号铭牌和人物海报；高亮只强调相框装饰，不改变人物档案交互。

## 光照与环境

- 场景采用晴日海天全景 `sunrise-ocean-panorama-seamless.png` 作为背景和环境反射。
- 天空半球光、暖色环境光与斜上方方向光共同提供日间照明和自然阴影。
- 场景保留连续海面、海天雾色、海面高光与展台的低强度海玻璃蓝边缘；不包含夜景、霓虹或区域射灯渐亮逻辑。

## 已移除的旧版结构

当前场景不包含下列旧版元素，后续维护不得因参考旧设计而重新引入：

- 玻璃幕墙、玻璃外墙、玻璃顶棚或桁架舱顶。
- 玻璃地面、室内浅水池或包裹步道的水槽结构。
- 以“封闭玻璃展馆”为前提的日出室内反射设计。

## 本地资源与路径

所有资源由 `web/public/gallery/generated/` 提供，不依赖外部 URL。

| 资源 | 运行时用途 |
| --- | --- |
| `calm-ocean-color-tile.png` | 开阔海面颜色、细节与 UV 滚动 |
| `light-travertine-color-tile.png` | 主步道和展台的洞石表面 |
| `frame-relief-champagne-brass-tile.png` | 相框外层、角件和铭牌的黄铜浮雕 |
| `compass-rose-inlay.png` | 入口步道罗盘嵌花 |
| `sunrise-ocean-panorama-seamless.png` | 晴日海天背景与环境反射 |

`roof-sail-sea-glass-tile.png`、玻璃细节贴图、早期全景及其他生成文件仅作为保留素材，当前开放式场景不加载它们。完整来源记录见 `web/public/gallery/ASSET_SOURCES.md`。

## 交互与兼容性

- PC 端使用 Pointer Lock 第一人称漫游：鼠标控制视角，`WASD` 或方向键移动，点击或 `E` 打开当前注视人物档案。
- 人物海报按邻近展位窗口懒加载；海报为空或加载失败时使用程序化占位海报。
- 小屏、触摸设备、WebGL 或 Pointer Lock 不可用时，页面保留二维人物档案列表。
- 场景资源、纹理、材质、几何体、渲染目标和事件监听均由既有 `dispose()` 生命周期释放。
