# 展馆维护入口

当前 `/gallery` 使用船长私人博物馆方案：舱室由 `web/src/gallery/MuseumRoom.ts` 实时构建，展品加载独立 GLB，海报由业务接口读取。旧整船 GLB 建筑方案及其生成、校验工具已退役。

设计与交互规范以 [船长的私人博物馆](gallery-design/museum.md) 为准；布局参数由 `web/src/gallery/layout.json`、`layout.ts` 与 `artifacts.ts` 维护。

## 当前资源

- `web/public/gallery/artifacts/`：草帽、和道一文字、果实、电话虫、记录指针与标识；来源与许可见该目录的 `ASSET_SOURCES.md`。
- `web/public/models/`：梅利号模型及许可。
- `web/public/gallery/flagship/materials/`：当前仍使用的胡桃木颜色、法线和黄铜颜色，共三张贴图。
- `web/public/gallery/museum/`：序厅截图、章节图集、人物图集与布鲁克画像，保留来源 JSON。
- `artifacts/gallery/model/`：当前展品的原始下载、可编辑源文件与检视记录。

## 验证与重建

```powershell
python scripts/gallery/prepare_materials.py
python scripts/gallery/validate_artifact_models.py
npm run build
npm run lint
.venv/Scripts/python.exe -m pytest -q
node scripts/gallery/check_browser.cjs
```

材质重建需要 Pillow/numpy；模型导入与自建展品重建需要 Blender，具体命令见设计文档。浏览器检查需要 Node 可解析 `playwright` 和本地 Chrome，可用 `NODE_PATH` 指向已有运行环境。浏览器容量测试使用接口拦截，不修改数据库。
