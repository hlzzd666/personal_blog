# 夜航工作台

2026-09-24 用户选定图 2 后要求进一步升级全页，重点是完整圆台底座跨出首屏，以及首屏之外具有不同阅读节奏和有意义的动态。方向由 `artifacts/about-design/2026-09-24/night/night.png` 与用户后续越界参考确定；当前实现以实际页面和 `DESIGN.md` 的 `/about` 局部规则为准。固定夜色只属于此页面，全站导航保留原内容与交互，仅适配颜色。

## 体验与结构

读者先通过月夜海面上的独立工作台认识作者，再翻阅项目档案、个人手记和工作航线，经过海岸生活场景，最终在明信片旁联系。页面的记忆点由完整器物轮廓、纸色阅读面和不同章节的布局形成，不把每个模块统一装入等大卡片。

- **签名场景：** 海景层单独裁切，RGBA 工作台独立叠放，厚圆台跨越首屏边界；章节导航为其预留净空。手机文案与器物上下排布，不依赖固定姓名长度。
- **签名交互：** 项目索引切换纸面档案，并联动高亮技能；工作航线按阅读进度延伸；联系明信片通过按钮切换到二维码。图像视差和纸面轻微倾斜服务于这些真实操作。
- **内容节奏：** 首屏 → 章节导航 → 项目档案 / 工具箱 → 个人手记 → 工作航线 → 海岸生活 / 所在地 → 本站说明 → 联系明信片。
- **数据边界：** 使用既有公开资料接口，项目、技能、经历、指标、兴趣与社交入口均可增减。空内容和请求失败有相应状态，不把本地或线上个人详情写入设计规则，不伪造成就、封面或技能百分比。

## 材料与动效预算

深海 `#061a22`、工作面 `#0d2933`、帆布字 `#f3edda` 与黄铜 `#e2bc74` 延续夜航方向；项目和明信片用 `#e8e0ca` 纸面形成阅读对比。复杂海景、航船和器物使用三张 WebP，合计约 620 KiB；简单罗盘符号与操作使用既有图标。海岸图同时用于生活区与明信片，明确属于主题插画。

唯一持续环境循环是首屏工作台的 11 秒轻浮动；其余空间动效由滚动、进入视口或用户操作触发。首屏与海岸前后层使用不同幅度，项目切换短促，经历条目单次显现，明信片不自动翻面。`useAboutMotion` 只更新可见场景，以按需 requestAnimationFrame 合并事件，不增加运行时依赖。实现为栅格分层和 CSS 空间变换，不宣称实时 3D 航船或流体模拟。

## 响应式与静态路径

1199px、900px 和 650px 逐级调整留白和分栏。手机项目索引横向滚动，选中项进入可见区域；项目详情、个人手记、工作经历与联系保持完整阅读。所在地地图为 185px 高的紧凑图面，隐藏重复标题，保留地图品牌及失败备用状态。

章节导航提供暂停开关，首屏离屏暂停浮动，页面隐藏停止场景更新；触屏不用鼠标视差。`prefers-reduced-motion` 与无观察器路径直接显示静态内容。项目索引支持键盘和 tab 语义，浅纸与深海表面都有可见焦点；简历继续使用原生对话框。接口、组件与帧回调在卸载时清理。
